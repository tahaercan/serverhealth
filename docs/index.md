# Server Health

A lightweight, privacy-first iOS monitor for your Linux servers — over SSH, directly from your phone. No agent on your servers. No third-party backend. No telemetry.

[**View source on GitHub**](https://github.com/tahaercan/serverhealth)

## What it does

- Add a Linux server with a one-time SSH key handshake.
- Pick from 22+ built-in checks (CPU, RAM, disk, load, bandwidth via `vnstat`, Docker, services, security updates, custom commands, and more).
- Set thresholds per rule.
- Receive a local notification when a threshold is crossed.
- Glance at server status from a home-screen widget.

## What it does NOT do

- It does not send data to any third-party server. Connections go directly from your phone to your boxes.
- It does not store your password. Your password is used **once**, to install an SSH key, and then forgotten.
- It does not run analytics, crash reporting, or advertising frameworks.
